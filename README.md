# CommutePop

这是一个基于 Godot 的 2D 超休闲消除游戏项目，中文名为“通勤消消乐”。项目目标是做出一个可快速上手、单局时长短、适合移动端竖屏体验的小型可上线原型。

## 项目结构

- `CommutePop/`：Godot 工程目录
- `docs/`：需求与选型分析文档

## 玩法简介

- 玩家点击或滑动相邻同色方块进行消除
- 消除后获得分数、连击反馈与音效反馈
- 每局有倒计时，结束后进入结算界面
- 支持最高分本地存档与音效开关

## 当前实现

- 主菜单
- 游戏主界面
- 基础消除逻辑
- 计分与倒计时
- 连击提示
- 结算界面
- 本地最高分记录
- 音效管理

## 运行方式

1. 用 Godot 4.x 打开 `CommutePop/` 目录下的 `project.godot`
2. 直接运行主场景
3. 默认主场景为 `Scenes/MainMenu.tscn`
